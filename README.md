# Buy or Bye? — Brutalist Financial Utility

A minimalist tool to calculate the cost of things in hours of your life, featuring AI roasts from cynical financial gurus.

## Tech Stack
- React 19 (Importmaps)
- Tailwind CSS
- Gemini AI API
- Clerk Auth

## Deployment to Vercel
1. Push to GitHub.
2. Connect Vercel to your repo.
3. Add Environment Variable: `API_KEY` (Gemini API Key).
4. Done.
